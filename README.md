# apple: Syau Sathi (स्याउ साथी)

An app for Nepali apple farmers: orchard knowledge, tree diagnosis, inputs delivered to a
collection point, and a buyer for the harvest.

| Folder | Contents |
| --- | --- |
| `app/` | Flutter app for farmers (Android first) |
| `console/` | Next.js + Tailwind web console for experts, suppliers, buyers and admins |
| `supabase/` | Database migrations, access rules, server functions, seed data |
| `content/` | Articles, images, audio manifest |
| `docs/` | Decisions log and milestone notes |

Status: Milestone 1 (Foundation) has started. See `docs/decisions.md`.
